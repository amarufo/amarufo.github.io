Aplicaciones

Herramientas web y de escritorio desarrolladas para apoyar la formulación de proyectos de inversión pública. Cada aplicación es independiente y cubre un módulo específico del ciclo de inversión.

🗺️

Diagnóstico Territorial Automatizado

Pipeline georreferenciado de preinversión

En vivo

Dada la ubicación del proyecto (latitud, longitud y ubigeo), la aplicación ejecuta más de 50 motores de análisis territorial y entrega un documento Word de ~40 páginas listo para el expediente técnico, con mapas, tablas e indicadores de demografía, riesgos, hidrología, clima y servicios.

  • Python
  • Streamlit
  • GeoPandas
  • Folium
  • Matplotlib
  • Pandas
Cómo usarlo
  1. Abre la aplicación con el botón de abajo.
  2. Ingresa la latitud, longitud y ubigeo del proyecto.
  3. Haz clic en «Generar Diagnóstico Territorial».
  4. Espera ~5 minutos y descarga el documento Word + ZIP con todos los datos.

Invierte IA

Automatización de estudios de preinversión

En vivo

Aplicación que aplica ciencia de datos e inteligencia artificial para automatizar los análisis más repetitivos de la formulación de un PIP: proyecciones de demanda, simulación Monte Carlo de costos y riesgos, y generación de resultados listos para integrar al estudio.

  • Python
  • Streamlit
  • Pandas
  • Scikit-learn
  • Monte Carlo
Módulos disponibles
  1. Análisis de demanda con proyecciones automáticas por método estadístico.
  2. Simulación Monte Carlo de costos y riesgos del proyecto.
  3. Modelado de incertidumbre en variables críticas del estudio.
  4. Generación de tablas y gráficos exportables para el expediente.

Dashboard — Mancomunidad Lima Sur

Indicadores de seguridad ciudadana para PIP

En vivo

Dashboard de análisis de brechas de seguridad ciudadana para Villa El Salvador, Villa María del Triunfo, San Juan de Miraflores, Pachacámac y Cieneguilla. Integra datos georreferenciados de la PNP, proyecciones del INEI y capacidades logísticas del RENAMU para sustentar un PIP de seguridad ante el MEF.

  • Python
  • Streamlit
  • GeoPandas
  • H3
  • Folium
  • Mermaid
Pestañas del dashboard
  1. Panorama general y posicionamiento frente a Lima Metropolitana.
  2. Análisis espacial avanzado con hotspots H3 y vectores delictivos.
  3. Auditoría logística y de capacidades RENAMU (series temporales).
  4. Arquitectura tecnológica e interoperabilidad (diagrama Mermaid).

PDF Tool

Suite CLI para trabajo documental con PDFs

Descargable

Suite CLI visual para Windows y Linux diseñada para el trabajo documental intensivo de oficina y expedientes técnicos. Menú guiado interactivo o comandos directos. Convierte PDFs a Markdown y JSON para uso con agentes de IA.

  • Python
  • CLI / TUI
  • PyMuPDF
  • Tesseract OCR
  • Docling
  • Marker PDF
Instalación rápida (Windows)
  1. Descarga o clona el repositorio con el botón de abajo.
  2. Doble clic en install_windows.bat y sigue las instrucciones.
  3. El instalador crea el entorno y un acceso directo en el Escritorio.
