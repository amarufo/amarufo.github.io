Automatización · Streamlit

Diagnóstico Territorial Automatizado

▼

Aplicación que, dada la ubicación de un proyecto de inversión pública (latitud, longitud y ubigeo), ejecuta un pipeline georreferenciado de más de 50 motores de análisis y entrega en menos de 5 minutos un documento Word de ~40 páginas listo para integrar en el expediente técnico.

  • Python
  • Streamlit
  • GeoPandas
  • Folium
  • Matplotlib
  • Pandas
  • NumPy

Principales resultados

  • Reduce de 40-80 horas a menos de 5 minutos la generación del diagnóstico territorial
  • Integra +15 fuentes oficiales: INEI, CENEPRED, ANA, SENAMHI, INGEMMET, OEFA, MINEDU, INDECI, MINCETUR, entre otras
  • Genera mapas temáticos exportables (peligros, uso de suelo, vías, demografía)
  • El documento Word sigue el contenido mínimo exigido para el diagnóstico en la Directiva N° 001-2019-EF/63.01

Dashboard · Seguridad ciudadana

Dashboard — Mancomunidad Municipal Lima Sur

▼

Dashboard interactivo en Streamlit para la Mancomunidad Municipal de Lima Sur (Villa El Salvador, Villa María del Triunfo, San Juan de Miraflores, Pachacámac y Cieneguilla). Consolida registros delictivos georreferenciados de la PNP, proyecciones del INEI y capacidades logísticas del RENAMU para sustentar un PIP de seguridad ciudadana ante el MEF.

  • Python
  • Streamlit
  • GeoPandas
  • H3 (Uber)
  • Folium
  • Mermaid
  • Pandas

Principales resultados

  • Análisis espacial de hotspots delictivos con celdas H3 a nivel de manzana
  • Indicadores de Presión Criminal, Capacidad Operativa y Brecha de Inversión por distrito
  • Comparativa de incidencia delictiva frente a Lima Metropolitana (tasa por 10,000 hab.)
  • Auditoría estadística interna de inconsistencias en registros RENAMU
  • Diagrama interactivo de arquitectura tecnológica propuesta (Mermaid)

Automatización · IA · Streamlit

Invierte IA

▼

Aplicación que aplica ciencia de datos e inteligencia artificial para acelerar la elaboración de estudios de preinversión en el marco INVIERTE.PE. Automatiza los análisis técnicos más repetitivos para que el formulador se concentre en el criterio técnico y la argumentación.

  • Python
  • Streamlit
  • Pandas
  • Scikit-learn
  • Monte Carlo

Funcionalidades

  • Análisis de demanda con proyecciones automáticas por método estadístico
  • Simulación Monte Carlo de costos y riesgos del proyecto
  • Modelado de incertidumbre en variables críticas
  • Generación de resultados listos para integrar al estudio de preinversión

Herramienta · CLI · Documentos

PDF Tool

▼

Herramienta CLI con interfaz visual de texto para trabajo documental intensivo con PDFs: foliado, firma digital, unión, división, protección por contraseña, conversión a texto y generación de salidas Markdown/JSON para agentes de IA. Diseñada especialmente para el armado de expedientes técnicos de inversión pública.

  • Python
  • CLI / TUI
  • PyMuPDF
  • Tesseract OCR
  • Docling
  • Marker PDF

Funciones principales

  • Foliar y firmar PDFs con vista previa interactiva
  • Unir, dividir, extraer, insertar, rotar y eliminar páginas
  • Agregar marca de agua, editar metadatos, proteger PDFs
  • Convertir PDF/DOCX a TXT, Markdown y JSON para agentes IA
  • Compatible con Windows y Linux. Instalación con un clic (batch/script)
